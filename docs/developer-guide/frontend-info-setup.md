# Heliks Informational Website Onboarding

This document guides developers through setting up the single-page marketing website locally.

##  Workspace Requirements
* **Node.js Environment:** Version `18.x` or `20.x`
* **Package Manager:** Standard `npm` framework

##  Execution Onboarding Sequence

### 1. Initialize Node Modules
```bash
npm install
```

### 2. Launch Local Environment Server
```bash
npm run dev
```

### 3. Pre-Commit Validation Routine
Before committing adjustments, run the validation check script to guarantee complete linting compliance:
```bash
npm run check
```
